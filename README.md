# 🛡️ ReportShield

**ReportShield** est une application Web SaaS conçue pour les analystes SOC, techniciens IT et prestataires de services informatiques (MSP). Elle permet de transformer rapidement des notes d'incidents brutes en rapports synthétiques et professionnels exportables au format PDF.

---

## 🚀 Fonctionnalités
- 📝 **Formulaire de saisie rapide :** Renseignement guidé des informations clés (Client, Sévérité, Périmètre, Cause racine, Recommandations).
- 👁️ **Aperçu en temps réel :** Visualisation instantanée du rendu final du document.
- 🖨️ **Génération PDF propre :** Exportation au format A4 avec mise en page optimisée pour les décideurs ("Executive-Ready").
- ⚡ **Performance :** Interface réactive développée avec les technologies Web les plus récentes.

---

## 🛠️ Stack Technique
- **Framework :** [Next.js](https://nextjs.org/) (React, App Router)
- **Styling :** [Tailwind CSS](https://tailwindcss.com/)
- **Icônes :** [Lucide React](https://lucide.dev/)
- **Langage :** TypeScript / JavaScript
